# Peeyoosh & Anamika — Wedding Invitation

A mobile-first static wedding invitation website, designed for WhatsApp sharing and GitHub Pages hosting.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Publish free with GitHub Pages
1. Create a new GitHub repository (for example `peeyoosh-anamika-wedding`).
2. Upload `index.html`, `README.md`, and the complete `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will provide your public website URL.

## WhatsApp sharing
After GitHub Pages publishes the site, share that URL in WhatsApp. The page includes a title, description and preview image metadata. Social preview caches can take time to refresh.

## Update images
Replace files inside `assets/` using the same filenames to retain the current layout.
